# 💸 Expense Tracker

> A modern, AI-native personal finance management platform built with **React, TypeScript, Node.js, Express, PostgreSQL, and Prisma**. Track expenses, manage budgets, monitor recurring bills, analyze spending habits, and visualize your financial health through an elegant, production-ready interface.

# ⚙️ Getting Started

## Clone Repository

```bash
git clone https://github.com/SupremeNexas/Expense-Tracker.git

cd Expense-Tracker
```

---

## Backend

```bash
cd backend

npm install

npm run dev
```

Backend runs on

```
http://localhost:5000
```

---

## Frontend

```bash
cd frontend

npm install

npm run dev
```

Frontend runs on

```
http://localhost:5173
```
